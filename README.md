# ブロック崩し

HTML 1ファイル（[`index.html`](index.html)）だけで動作する、シンプルなブラウザ向けブロック崩しゲームです。  
外部ライブラリや画像・音声ファイルを一切使わず、HTML / CSS / JavaScript（`<canvas>`）のみで実装しています。

## ゲームの概要

- **全3ステージ制**: ステージが進むごとにブロック数（30個 → 40個 → 60個）とボールの速度が段階的に上がります。
- **マルチボール**: ブロックを **10個消すごとにボールが1つ増える** ため、後半になるほど画面が賑やかになります。
- **軽量・即起動**: [`index.html`](index.html) をブラウザで開くだけですぐに遊べます。

---

## 遊び方（操作方法）

### 起動方法
[`index.html`](index.html) をブラウザで直接開いてください。

### 操作方法
| 操作 | 入力方法 |
| --- | --- |
| パドルの移動 | マウス移動 / タッチドラッグ / `←` `→` キー / `A` `D` キー |
| ボールの発射・次ステージへ進む・リスタート | 画面クリック / `Space` キー / `Enter` キー |

### ルール
- 初期ライフ（`LIVES`）は **3** です。
- ブロックを1つ壊すごとにスコアが **+10** 加算されます。
- ブロックを **10個消すごとにボールが1つ追加** されます（画面上部に次の追加までの残り個数が表示されます）。
- ボールが複数ある間は、1つ下に落ちても残りのボールでゲームが続行します。**画面上のすべてのボールを落とした場合のみ** ライフが1減ります。
- ステージ1・2をクリアすると次のステージへ進み、ステージ3をクリアすると **ALL STAGES CLEAR!** となります（スコアとライフはステージ間で引き継がれます）。

## 工夫した点

1. **1ファイル完結とフレームレート非依存の動作**
   - `<canvas>`（640×480）と標準の Web API のみで構成し、環境構築不要で遊べるようにしました。
   - `requestAnimationFrame` の経過時間 `dt`（最大 `0.033` 秒で制限）をもとに移動量を計算しているため、高リフレッシュレート環境でも一定速度で動作します。

2. **狙いやすい反射角制御と安定した衝突判定**
   - パドルの中心から左右のどこに当たったかに応じてボールの反射角（最大 ±60°）が変化するようにし、狙った方向へ打ち返せるようにしました。
   - ブロックとの衝突時は X/Y 軸の重なり量を比較して反射方向を決め、1フレームにつき1ブロックまで処理することで、めり込みや意図しない二重反転を防いでいます。
   - 10個消した際に増える追加ボールは、縦方向の最小速度（現在速度の 25% 以上）を確保し、水平近くで往復し続けて詰まるのを防いでいます。

3. **状況がひと目でわかる HUD とマルチボール時のライフ判定**
   - 画面上部に `STAGE` / `SCORE` / `BALLS (あと N 個で+1)` / `LIVES` を表示し、次にボールが増えるタイミングを把握しやすくしました。
   - マルチボール中は「最後の1球が落ちたときだけライフが減る」判定にすることで、複数ボールならではの爽快感を保っています。

4. **文字列マップによるステージ管理と10の倍数設計**
   - `STAGES` のレイアウトを文字列の配列で定義し、配置パターンの確認や調整をしやすくしました。
   - すべてのステージのブロック数を10の倍数（30 / 40 / 60 個）に揃えており、「10個消すごとにボール増加」のリズムとステージ進行が自然に噛み合うようにしています。

## 作りながら変えた点（開発の変遷）

コミット履歴に沿って、最小構成から段階的に機能とバランスを調整しました。

1. **最小構成からのスタート**（`10e8e76`）
   - 最初は「1ステージ（5行×8列＝40個）・ボール1個・スコアとライフ表示のみ」という最小限のブロック崩しとして実装しました。

2. **3ステージ制とマルチボールの導入**（`4f5440d`）
   - 単発で終わる構成から、ステージごとに配置とボール速度（`350` → `380` → `410`）が変化する3ステージ制へ拡張しました。
   - あわせてボール管理を単一オブジェクトから配列管理へ変更し、「ブロックを10個消すごとにボールが1つ増える」仕組みと、HUD へのステージ・ボール数・残り個数表示を追加しました。

3. **ステージ進行に応じたブロック数の再調整**（`5e17c3b`）
   - 3ステージ制を導入した直後は、各ステージのブロック数が `40個 → 30個 → 40個` となっており、Stage 2 で一度ブロック数が減っていました。
   - ステージを重ねるごとに手応えとボリュームが増していくようにレイアウトを作り直し、`30個 → 40個 → 60個` へと段階的に増える構成へ変更しました。
